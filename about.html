About This Project

ML-Based System Health Monitoring Using OS Data, DBMS, and Algorithm Analysis

Project Purpose

This project uses Machine Learning to predict and monitor system health. By analyzing critical resource utilization, the system can determine the overall health state and classify it as Healthy, Warning, or Critical.

The model analyzes the following key metrics:

  • CPU usage: Processor load and performance metrics
  • Memory usage: RAM utilization and availability
  • Disk usage: Storage space and I/O load
  • DBMS load: Database queries and transaction volume
